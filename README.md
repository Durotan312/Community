# Connected Community

Внутренний портал компании: новости, справочник сотрудников, заявки с согласованием, календарь, задачи,
карта офиса, база знаний с AI-помощником, Telegram-боты. Flask + SQLite + чистый JavaScript, без сборки.

## Запуск

```
pip install -r requirements.txt
python app.py
```

Портал откроется на http://127.0.0.1:5000. База `portal.db` создаётся сама при первом запуске.
Ключ AI кладётся в файл `api_key.txt` рядом с `app.py` или в переменную окружения — в репозитории его нет.
Почта, турникеты и Telegram настраиваются переменными окружения (см. `docker-compose.yml`).

## Проверки

`python checks/run.py` — правила интерфейса, все адреса API под каждой ролью, права и защиты, боты.
Запускается сам при `git push` (хук `.githooks/pre-push`).

## Что не входит в открытую копию

Внутреннее описание компании, данные сотрудников, загруженные файлы и ключи живут только в закрытом репозитории и на сервере.
